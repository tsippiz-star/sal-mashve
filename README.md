# 🛒 סל משווה – השוואת מחירי מזון בישראל

אפליקציית ווב חינמית להשוואת מחירי סל קניות בין 6 הרשתות הגדולות בישראל
(שופרסל, רמי לוי, יוחננוף, ויקטורי, אושר עד, טיב טעם).
מבוסס על קבצי "שקיפות מחירים" הרשמיים שהרשתות מחויבות לפרסם בחוק.

## 🚀 להפצה מהירה של האתר לאינטרנט
📖 **[קראי קודם: `הפצה_מהירה.md`](הפצה_מהירה.md)** – 10 דקות ואת מפרסמת את האתר לעולם, בלי להתקין כלום.

## 📁 מבנה הפרויקט

```
price-comparison-bot/
├── README.md                    # זה הקובץ
├── הפצה_מהירה.md               # 🌟 מדריך פריסה מהיר (10 דקות)
├── DEPLOY.md                    # מדריך פריסה מפורט
├── TELEGRAM_BOT.md              # מדריך בוט טלגרם (אלטרנטיבה)
├── requirements.txt             # תלויות Python
├── .github/workflows/
│   └── scrape.yml               # 🤖 עדכון אוטומטי יומי
├── static/
│   └── manifest.json            # 📱 הגדרות PWA
└── src/
    ├── app.py                   # 🌐 אפליקציית ווב (Streamlit)
    ├── scraper.py               # מוריד מחירים מהרשתות
    ├── matcher.py               # התאמת שם חופשי → מוצר
    ├── comparator.py            # חישוב סל וחיסכון
    └── telegram_bot.py          # אלטרנטיבה: בוט טלגרם
```

## 💻 הפעלה מקומית (לא חובה, רק אם רוצה לפתח)

```bash
python -m venv venv
source venv/bin/activate           # Windows: venv\Scripts\activate
pip install -r requirements.txt

python src/scraper.py --chains shufersal --limit 5   # מוריד נתונים ראשונית
streamlit run src/app.py                              # אתר מקומי בכתובת localhost:8501
```

## ⚠️ מגבלה חשובה
שרתי `url.publishedprices.co.il` נגישים רק מ-IP ישראלי. GitHub Actions ו-Streamlit Cloud
רצים מארה"ב/אירופה – ולכן רק **שופרסל** נגישה משם.

**פתרונות:**
- הרצת ה-scraper פעם ביום ממחשב פרטי בישראל
- Raspberry Pi ביתי (₪250 חד-פעמי) עם Cron יומי
- שדרוג ל-Israel VPS (~$5 בחודש)
